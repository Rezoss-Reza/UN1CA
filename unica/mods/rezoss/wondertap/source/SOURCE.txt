Source and provenance for the experimental module binaries

driver-source.tar.gz preserves the modified Qualcomm driver, Wonder frontend,
provider and compatibility overlay used for these candidates. Consult included
source license headers. provenance.json records upstream origins. patches/
preserves the backport changes; build scripts preserve the research build flow.
The scripts reference the archived reconstructed 5.15.220 build directory and
require its generated configuration, Module.symvers and Clang toolchain.

To extract an isolated source tree and rebuild all three debug modules:
  source buildenv.sh dm3q
  bash unica/mods/rezoss/wondertap/source/rebuild.sh
The build leaves artifacts in the printed /tmp directory. It does not overwrite
ROM payloads, update manifest hashes or access a device. The backend build now
passes WLAN_CTRL_NAME=wlan and refuses a linked module without the native
/dev/wlan state-control callbacks.
It also sets CHIP_NAME=kiwi_v2 so firmware/INI requests match Samsung's installed
kiwi_v2 directory, and rejects the previous qca_cld3_kiwi_v2 config path in the
linked result. The module identity remains qca_cld3_kiwi_v2.

Patch 0012 adds the genuine GPL-2.0-only Minstrel HT implementation from the
reconstructed kernel into Wonder. Copyright/license headers are preserved.
Only public mac80211 types and exports are required; two exact local timing
helpers avoid unexported internal dependencies. The private algorithm name
wonder_minstrel_ht is explicitly selected by Wonder and is registered before
its platform driver. Unload unregisters the platform driver before the rate
controller. Source and active patch are both included in this directory's
updated snapshot. Samsung's mac80211 binary is not replaced.
